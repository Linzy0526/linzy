# 生产服务器准备与部署

> 本文主要介绍在 huweicloud Ubuntu Linux 服务器 nginx、node、mysql 安装及配置

### nginx

1. 安装 Nginx 软件包

```
sudo apt-get install nginx
```

安装后的路径 /etc/nginx

2. 启动 Nginx 服务

```
sudo systemctl start nginx
```

3. 确认 Nginx 是否正在运行

```
sudo systemctl status nginx
```

4. 配置代理

```
server {
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

配置完之后执行重启命令，重启服务器

```
sudo systemctl restart nginx
```

### Node.js

1. 添加官方 PPA

```
curl -sL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
```

2. 安装 Node.js

```
sudo apt-get install -y nodejs
```

### mysql

1. 安装

```
sudo apt-get install mysql-server
```

2. 启动 MySQL 服务

```
sudo systemctl start mysql
```

3. 配置 MySQL 安全性

```
sudo mysql_secure_installation
```

这将引导通过一些简单的选项来加强 MySQL 的安全性。

4. 配置 MySQL 允许远程 SSH 连接

编辑 MySQL 的配置文件 /etc/mysql/mysql.conf.d/mysqld.cnf，将其中的 bind-address 一行注释掉或将其改为 0.0.0.0，以允许来自任何 IP 地址的远程连接。

```
#bind-address = 127.0.0.1
bind-address = 0.0.0.0
skip-networking = 0
```

5. 在 MySQL 中创建一个新用户

root 用户不能让外部 ip 访问，所以需要新增一个用户并赋予权限去访问

```sql
CREATE USER 'yourusername'@'%' IDENTIFIED BY 'yourpassword';

GRANT ALL PRIVILEGES ON *.* TO 'yourusername'@'%';

FLUSH PRIVILEGES;
```

6. 重启服务

```
sudo systemctl restart mysql
```

注：如果还是无法通过 ssh 访问，需要需考虑云服务器的 **安全组** 配置，允许3306端口访问。
