# 表数据关联查询

## 一对一关系

prisma/schema.prisma 下的文件配置

```prisma
model User {
 id      Int      @id @default(autoincrement())
 profile Profile?
}

model Profile {
 id     Int  @id @default(autoincrement())
 user   User @relation(fields: [userId], references: [id])
 userId Int // 关系标量字段 (在上述 `@relation` 属性中使用)
}

// 还可以通过多个字段进行一对一的关系连接
model User {
 id      Int      @id @default(autoincrement())
 name    String
 old     Int
 profile Profile?
}

model Profile {
 id        Int  @id @default(autoincrement())
 userName  Int
 userOld   Int
 user      User @relation(fields: [userName, userOld], references: [name, old])
}
```

代码查询, 可以使用 include 关键字来指定要包含的关联模型

```typescript
prisma.User.findMany({
  where: { id: 1 },
  include: { profile: true },
});
```

## 一对多关系
prisma/schema.prisma 下的文件配置

```prisma
model User {
  id    Int    @id @default(autoincrement())
  posts Post[]
}

model Post {
  id       Int  @id @default(autoincrement())
  author   User @relation(fields: [authorId], references: [id])
  authorId Int
}

// 一个表中有两个ID需要关联另一一个同一字段，需要特殊注明关联关系 
model User {
  id    Int    @id @default(autoincrement())
  inviterRecord InviteRecord[] @relation("inviter")
  inviteeRecord InviteRecord[] @relation("invitee")
}

model InviteRecord {
  id       Int  @id @default(autoincrement())
  inviter   User @relation("inviterId", fields: [inviterId], references: [id])
  inviterId Int
  invitee   User @relation("inviteeId", fields: [inviteeId], references: [id])
  inviteeId Int
}
```

代码查询, 可以使用 include 关键字来指定要包含的关联模型

```typescript
prisma.User.findMany({
  where: { id: 1 },
  include: { invitee: true,  inviter: true},
});
```
