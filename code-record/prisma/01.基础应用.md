## 安装相关依赖

`npm install prisma --save-dev` 

用于安装和管理 Prisma 的命令行工具，并提供了许多实用的命令和工具，如 `prisma init`、`prisma migrate` 等

`npm install @prisma/client`  

它是Prisma 的 Node.js 客户端，它提供了一种类型安全、可靠、易于使用的方法来访问数据库，可以使开发人员更轻松地编写和执行数据库查询


## Prisma Cli 常用命令

初始化一个新的 Prisma 项目，并创建一个 prisma/schema.prisma 文件，该文件定义了数据库模式和表的结构、字段、关系等信息  
`npx prisma init`   

根据 prisma/schema.prisma 文件自动生成 Prisma Client，用于在 Node.js 应用程序中访问和操作数据库  
`npx prisma generate`

用于进行数据库迁移，包括创建、修改和删除数据库表、字段和关系等操作   
`npx prisma migrate`   

删除数据库中所有表和数据  
`npx prisma reset` 

将 prisma/schema.prisma 文件中定义的数据库模式部署到 Prisma 服务器上  
`npx prisma deploy` 

启动一个 Web 界面，可以在其中查看和编辑数据库内容，包括表、记录、关系等  
`npx prisma studio` 

当我们修改 prisma/schema.prisma 文件后要运行哪些命令？   
1.可以运行`npx prisma generate`  `npx prisma migrate`  
2.开发环境可以直接用`npx prisma migrate dev --name init` 这条命令执行后会自动执行`npx prisma generate`


## Prisma 模型配置

### schema.prisma 参数配置

``` prisma
// /prisma/schema.prisma
datasource db {
  provider = "mysql" // postgresql | mysql
  url      = env("DATABASE_URL") // 可以直接填写字符串链接，也可以通过环境变量方式注入
}

generator client {
  provider = "prisma-client-js" // 生成器，一般不改
}

model User {
  // @id 代表该字段为主键ID
  id                  Int                @id @default(autoincrement())
  // 设置类型后可以通过@db.xx给类型设置长度
  name                String?            @db.VarChar(255)
  // @unique 表示表中字段的唯一性
  cellphone           String             @unique
  avatar              String?
  wxOpenId            String             @unique @db.VarChar(255)
  // @@map允许你将模型或字段映射到数据库中的特定名称
  loverId             Int?               @unique @@map("lover_id")
  credit              Int?               @default(0)  // @default 可以设置默认值
  createdAt           DateTime           @default(now())
  updatedAt           DateTime           @default(now()) @@comment
  goodsOrder          GoodsOrder[]      
  inviteeInviteRecord UserInviteRecord[] @relation("invitee")
  inviterInviteRecord UserInviteRecord[] @relation("inviter")
}

model UserInviteRecord {
  id        Int      @id @default(autoincrement())
  inviterId Int
  // 关联查询数据，通过设置外键的方式关系表，主表也需要注明关联表的数据
  // 如果该表有两个外键需要注明外键名，如果只有一个主表的@relation('xx')和子表的"外键名可以省略"
  inviter   User     @relation("inviter", fields: [inviterId], references: [id])
  inviteeId Int
  invitee   User     @relation("invitee", fields: [inviteeId], references: [id])
  status    Int
  createdAt DateTime @default(now())
  updatedAt DateTime @default(now())
}

```
