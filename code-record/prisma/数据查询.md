# 表数据查询

### 唯一标识符获取记录 findUnique

- 唯一标识符查询，筛选字段必须为设计表字段是唯一的字段(@unique)

```typescript
const where: Prisma.UserWhereUniqueInput = {
  email: "elsa@prisma.io",
};
// 按唯一标识符
const user = await prisma.user.findUnique({
  where,
});
```

- 除了一个字段作为唯一外，还可以将多个字段组合成为一个唯一字段做判断

```prisma
model User {
  cellphone Int
  email   String

  @@id([cellphone, email])
}
```

```typescript
const timePeriod = await prisma.user.findUnique({
  where: {
    cellphone_email: {
      quarter: 13100000000,
      email: "elsa@prisma.io",
    },
  },
});
```

注：MongoDB 不支持

### 获取所有记录 findMany

- 根据条件筛选记录

```typescript
const where: Prisma.UserWhereInput = {
  email: "elsa@prisma.io",
};
const users: User[] = await prisma.user.findMany({
  where,
});
```

- 查询排序 orderBy
  查询到的记录排序主要分为正序（asc）和倒序（decs）进行排序

```typescript
const users: User[] = await prisma.user.findMany({
  where,
  orderBy: {
    id: "asc",
  },
});
```

- 分页查询记录 skip、take

skip: 跳过多少个；take：取多少记录。实际应用中 pageNo 和 pageSize 需要做对应的转换

```typescript
const users: User[] = await prisma.user.findMany({
  skip: (pageNo - 1) * pageSize,
  take: pageSize
  where,
});
```

- 查询今天创建所有数据 gt、gl
  where 对象中的 createdAt 字段用于指定数据的创建时间，gte 和 lte 运算符用于指定范围

```typescript
const todayStart = new Date();
todayStart.setHours(0, 0, 0, 0); // 将时间设置为今天 0 点
const todayEnd = new Date();
todayEnd.setHours(23, 59, 59, 999); // 将时间设置为今天 23:59:59.999
const users: User[] = await prisma.user.findMany({
  where: {
    createdAt: {
      gte: todayStart,
      lte: todayEnd,
    },
  },
});
```
