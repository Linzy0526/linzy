# 事务

> 事务是指将一系列的数据库操作作为一个单元进行处理的方式。它要么全部成功执行，要么全部回滚到操作前的状态，以确保数据的完整性和一致性。如果在事务中的任何一个操作失败，所有的操作都将被回滚，就好像从未执行过一样。为了实现这样的需求，我们可以使用Prisma框架中提供的$transaction方法来管理事务。


#### 参数为数组的方式实现

```typescript
const result = await prisma.$transcation([
  prisma.user.update(),
  prisma.task.update(),
]);
```

从左往右执行数组内业务，这种写法可以实现回滚，但是不能对做额外的业务逻辑处理，主动抛出异常去中断事务

#### 参数为回调函数

```typescript
const result = await prisma.$transcation(async (p: Omit<
        typeof prisma,
        '$connect' | '$disconnect' | '$on' | '$transaction' | '$use'
      >,
    ) => Promise<any>) => {
  const user = await p.user.update();

  if (user.xx) {
    throw new Error("xx");
  }
  await p.task.update();
});
```

在回调函数内部执行同步的业务逻辑，可以主动抛出异常进行回滚，同时也可以处理其他的逻辑。

注：回调函数内部的prisma实例对象必须引用回调函数抛出的实例参数作为prisma实例对象，不然无法进行正常回滚
