# 解决纹理图片比较多内存溢出的问题


#### 前景

前段时间在做一个3D相册的项目，目的是将所有的的图片已3D的方式渲染到页面中。项目应用的是 `three.js` 库是实现元素的渲染和动画。

最开始我应用的是 `WebGLRender` 来作为渲染器，在图片比较少的时候能够正常渲染，但是在图片逐渐增加的时候，页面出现了卡死，最后页面甚至崩溃，即内存占用太高导致的问题。

#### 原因

由于我是将每张图片作为一个纹理对象，而每个纹理对象加载的图片会存储到内存中，导致内存飙升，最后导致了页面崩溃。

``` js
const loader = new THREE.TextureLoader()
    for (let i = 0; i < images.length; i++) {
    loader.load(images[i], () => {
        const photoMaterial = new THREE.MeshBasicMaterial({
        map: texture.clone(),
        opacity: 1.0,
        });
        photoMaterial.needsUpdate = true;
        const object = new THREE.Mesh(photoGeometry, photoMaterial);
        scene.add(object);
        objects.push(object);
    })
}
```

#### 解决1：使用CSS3DRender

由于 `CSS3DRender` 会将元素直接渲染成 `Element` 元素，并将图片已 `css` 的方式将图片渲染出来，并不会将图片存储到内存中。

``` js
 for (let i = 0; i < images.length; i++) {
    //125为照片的个数，随便放多少，不过要适中
    let element = document.createElement("div");
    element.className = "element"; //给图片加类名即设置对应的图片大小
    element.style.backgroundImage = `url(${images[i]})`; // 背景图片 图片名称是 1...11sss8.jpg
    element.style.backgroundSize = "cover"; //保持图像的宽高比例，将图片缩放到正好完全覆盖定义的背景区域
    element.name = i; // 给元素的name属性赋值，以便获取鼠标点击的ss当前值
    element.setAttribute("data-id", images[i].id || Date.now());
    let object = new CSS3DObject(element); //可以将HTML元素作为纹理添加到3D对象中，从而创建有趣的3D特效
    scene.add(object);
    objects.push(object); //为了知道被添加到照片元素的个数
  }
```

缺点：每个元素时一个 `Element DOM`，在元素比较多的时候，对图片做动画切换时存在卡顿的问题。

#### 解决2：使用WebGLRender，并使用纹理合集

由于之前我是将每个图片都生成一个纹理对象，导致内存占用过高

那我们是不是可以通过类似 `CSS精灵图` 的方式？

##### 1. 合成图片

将目录下面的图片合成到一张图片，并输出一张合集图片和一个json数据，json数据中包含了原图片名与图片位置的映射关系。

##### 2. 应用图片纹理合集

``` js
const photoGeometry = new THREE.BoxGeometry(32, 32, 4);
new THREE.TextureLoader().load("合集图片地址",
(texture) => {
    texture.minFilter = THREE.LinearFilter;
    texture.magFilter = THREE.LinearFilter;
    texture.format = THREE.RGBAFormat;
    texture.colorSpace = THREE.SRGBColorSpace; // 添加这个不会让图片模糊泛白
    const altsWidth = texture.source.data.width;
    const altsHeight = texture.source.data.height;
    //放图片
    for (let i = 0; i < images.length; i++) {
    const texturePosition = textureData[images[i].fileName];
    const photoMaterial = new THREE.MeshBasicMaterial({
        map: texture.clone(),
        opacity: 1.0,
    });
    photoMaterial.needsUpdate = true;

    // 设置子纹理的UV坐标，repeat 和 offset 都是占整张图的比例值，每个值的范围都是0-1
    photoMaterial.map.repeat.set(
        texturePosition.width / altsWidth,
        texturePosition.height / altsHeight
    );
    photoMaterial.map.offset.set(texturePosition.x / altsWidth, texturePosition.y / altsHeight);

    const object = new THREE.Mesh(photoGeometry, photoMaterial);
    object.position.set(createRandom(), createRandom(), createRandom());
    scene.add(object);
    objects.push(object); //为了知道被添加到照片元素的个数
    }
})
```
