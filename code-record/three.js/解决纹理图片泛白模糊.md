# 解决纹理图片泛白模糊

#### 背景

在项目中应用了图片纹理，但是看起来有点泛白模糊，效果不佳

``` js
const photoGeometry = new THREE.BoxGeometry(32, 32, 4);
new THREE.TextureLoader().load("图片地址",
(texture) => {
    const texturePosition = textureData[images[i].fileName];
    const photoMaterial = new THREE.MeshBasicMaterial({
        map: texture.clone(),
        opacity: 1.0,
    });
    const object = new THREE.Mesh(photoGeometry, photoMaterial);
    scene.add(object);
    objects.push(object); //为了知道被添加到照片元素的个数
})
```

效果如下图：
![泛白效果图](https://github.com/Linzy0526/linzy-markdown-image/blob/main/github-linzy/three/%E7%BA%B9%E7%90%86%E6%B3%9B%E7%99%BD%E5%9B%BE.png)

#### 解决

``` js
// three.js version 0.157.0

texture.encoding = THREE.encoding // 当前版本已注释弃用，但是有效果

texture.colorSpace = THREE.SRGBColorSpace; // 新版本推荐使用这个
```

效果如下图：
