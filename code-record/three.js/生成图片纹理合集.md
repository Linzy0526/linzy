# 生成图片纹理合集

#### 为什么要生成？

在 `WebGLRendr` 中使用纹理图片会将图片缓存到内存中，当图片纹理过多会导致内存占用过高。

#### 图片纹理的UV坐标

由于图片纹理的坐标可能与大家想象的 `CSS精灵图` 的坐标不太一样，这里简单的做一个描述。

它的轴方向有点像数学中正数坐标轴，顶点UV坐标可以在0~1.0之间任意取值，纹理贴图左下角对应的UV坐标是(0,0)，右上角对应的坐标(1,1)

#### 使用 Jimp 将图片合成到一张图片上并输出具体的位置

`Jimp` 是一个用于处理图像的 JavaScript 库。它允许你在 `Node.js` 环境中进行各种图像处理操作，如裁剪、缩放、旋转、过滤、文本叠加等。`Jimp` 提供了一个易于使用的 API，使图像处理变得相对简单。

1.安装Jimp依赖
``` shell
npm install jimp
```

2.读取目录下的图片文件，并预设横轴和纵轴上的个数

3.创建一个足够容量的空图片用于填充图片

``` js
const imageSize = 64;
// 创建一个空底图，设置底图的宽度和高度
const atlasWidth = xCount * imageSize; // 底图宽度

const atlas = new Jimp(atlasWidth, atlasHeight);
```

4.对图片进行裁剪和缩放（项目中由于只需使用图片居中那块）

``` js

const height = texture.getHeight();
```

#### 完整代码

``` js
const fs = require('fs');
const Jimp = require('jimp');
const imageSize = 64;
async function mergeSquareImagesInDirectory(inputDirectory, outputImagePath) {
  try {
    // 读取目录中的所有文件
    const files = fs.readdirSync(inputDirectory);
    const xCount = 10;
    const yCount = Math.ceil(files.length / 10);


    // 创建一个空底图，设置底图的宽度和高度
    const atlasWidth = xCount * imageSize; // 底图宽度
    const atlasHeight = yCount * imageSize; // 底图高度
    const atlas = new Jimp(atlasWidth, atlasHeight);

    // 存储每个纹理的位置信息
    const texturePositions = [];

    let x = 0;
    let y = 0;
    let xIndex = 0;
    let yIndex = 0;

    for (const file of files) {
      const filePath = `${inputDirectory}/${file}`;

      // 读取图像
      const texture = await Jimp.read(filePath);

      // 获取图像的宽度和高度
      const width = texture.getWidth();
      const height = texture.getHeight();

      // 计算截取的正方形区域的位置和大小
      let squareSize = Math.min(width, height);
      let cropX = (width - squareSize) / 2;
      let cropY = (height - squareSize) / 2;

      // 截取图像中间的正方形部分
      texture.crop(cropX, cropY, squareSize, squareSize);

      // 缩放图像到指定大小
      texture.resize(imageSize, imageSize);

      // 将图像复制到底图的当前位置
      atlas.blit(texture, x, y);

      // 记录纹理的位置信息
      texturePositions.push({
        file: file,
        x,
        y: (yCount - yIndex - 1) * imageSize,
        width: imageSize,
        height: imageSize,
      });

      // 更新下一个纹理的位置
      x += imageSize;
      xIndex++;

      if (x + imageSize > atlasWidth) {
        // 如果x超出底图宽度，换行
        x = 0;
        xIndex = 0;
        y += imageSize;
        yIndex++;
      }
    }


    // 保存合并后的底图
    await atlas.writeAsync(outputImagePath);

    return { atlasPath: outputImagePath, texturePositions };
  } catch (error) {
    console.error('Error:', error);
    return null;
  }
}

// 示例用法
const inputDirectory = 'friend-circle-qiniu'; // 存储图片的本地目录
const outputImagePath = 'path_to_output_image2.png'; // 合并后的纹理集合保存的文件路径

mergeSquareImagesInDirectory(inputDirectory, outputImagePath)
  .then((result) => {
    if (result) {
    //   console.log('Texture atlas saved to:', result.atlasPath);
    //   console.log('Texture positions:', result.texturePositions);
      const map = {};
      console.log("result.texturePositions", result.texturePositions.length)
      result.texturePositions.forEach(item => map[item.file] = item)
      fs.writeFileSync("texture_data.json", JSON.stringify(map))
    } else {
      console.log('Texture merging failed.');
    }
  });
```
