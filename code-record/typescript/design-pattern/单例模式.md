# 设计模式——单例模式

单例模式是一种常见的设计模式，用于确保在整个应用程序中只存在一个类的实例。这个实例通常用于协调访问共享资源，配置或状态的情况。单例模式确保了类的单一实例，并提供了一种全局访问这个实例的方式。

### 实现方式

``` js
class Singleton {
  private static instance: Singleton | null = null;

  constructor() {
    if (!Singleton.instance) {
        Singleton.instance = this;
    }
    return Singleton.instance;
  }
}
  ```

### 日常应用场景

- axios库， 我们使用 axios.create 创建了一个全局 Axios 实例，并配置了一些默认的请求选项。然后，我们可以在整个应用程序中重复使用 instance 来发送 HTTP 请求，确保了全局的一致性和性能优化。
- vuex库，它也使用单例模式来确保在整个应用程序中只存在一个状态存储实例。这有助于确保应用程序的不同组件之间可以共享
- ant/Message, 常用的Antd中，message组件相信大家也不陌生了，其实他的弹窗组件也用到了单例模式
